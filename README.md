# React Сайт — Услуги и Telegram-боты

Современный адаптивный сайт с React, встроенным Google Form и красивым дизайном.

## 📋 Что включено

✅ **React 18** + **Vite** для быстрой разработки  
✅ **Полностью адаптивный** дизайн (мобилька, планшет, десктоп)  
✅ **Google Form** встроен в красивый модальный диалог  
✅ **Все стили** из исходного HTML с улучшениями  
✅ **Smooth scroll** между секциями  
✅ **Sticky nav** с активными ссылками  
✅ **Animations** и красивые переходы  

## 🚀 Быстрый старт

### 1️⃣ Установи зависимости
```bash
npm install
```

### 2️⃣ Запусти локально
```bash
npm run dev
```
Сайт откроется на `http://localhost:5173`

### 3️⃣ Замени ссылку на свой Google Form

В файле `App.jsx` найди эту строку (примерно строка 193):
```jsx
src="https://docs.google.com/forms/d/e/1FAIpQLSdgf9lR6j8c_example/viewform?embedded=true"
```

И замени на свою ссылку. Чтобы получить правильный URL:
1. Открой свой Google Form
2. Нажми кнопку "Отправить" (с иконкой стрелки)
3. Выбери "Встроить" (</>)
4. Скопируй ссылку из атрибута `src="..."`
5. Вставь её в код

### 4️⃣ Собери проект для публикации
```bash
npm run build
```

Готовый проект появится в папке `dist/`

## 📱 Особенности адаптива

- **Мобильные** (до 640px): меню складывается, таблицы оптимизированы
- **Планшеты** (640px - 820px): двухколоночный макет становится однобалочным
- **Десктоп** (820px+): полный макет с блобами и анимациями

## 🎨 Кастомизация цветов

В файле `App.css` в корне есть CSS переменные:

```css
:root {
  --rose: #B5697A;
  --rose-dark: #8F4C5C;
  --sage: #6E8B5A;
  --sage-dark: #566F46;
  /* и тд */
}
```

Меняй значения и цвета изменятся везде.

## 🐛 Если что-то не работает

1. **Google Form не открывается** — проверь ссылку в `src="..."`
2. **Стили странные** — очисти кэш браузера (Ctrl+Shift+Delete)
3. **Ошибки при `npm install`** — удали `node_modules` и `package-lock.json`, переустанови
